# PumpSwap v2 CPI support — 8 October 2026

Local source/build update, not deployed. Official upstream IDL/docs commit:
`8cda1fa30ea658b20909d8aedf002047119388d2` in pump-fun/pump-public-docs.

Append unit Dex variants `PumpfunammBuyV2` (104) and `PumpfunammSellV2` (105).
Keep existing tags 73/74 unchanged. The compact and legacy router dispatchers
share these handlers. Buy calls `buy_exact_quote_in_v2`, sell calls `sell_v2`.
Both encode two u64 arguments after the 8-byte selector, without a track-volume
byte. The per-hop minimum is 1; final minimum return and outer profit guard are
unchanged.

Each v2 hop consumes exactly seventeen router roles:

| Index | Role |
| --- | --- |
| 0 | PumpSwap program |
| 1 | trading authority |
| 2 / 3 | source / destination token account |
| 4 | pool |
| 5 | global config |
| 6 / 7 | base / quote mint |
| 8 / 9 | base / quote vault |
| 10 / 11 | base / quote token program |
| 12 | system program |
| 13 | user volume accumulator |
| 14 | fee config |
| 15 | buyback quote ATA |
| 16 | event authority |

CPI maps these roles to official IDL order; buys map destination/source to
user base/quote, sells map source/destination. Only the trading authority signs.
Both directions use existing hop-continuity checks, SA token allowlist,
post-transfer checks and bounded rent reimbursement to the router authority.
Missing account windows/payer return errors rather than indexing/unwrapping.

The Rust client opts in using `pump_trade_v2: true` in its full trade-graph run
JSON, after deploying and verifying this router. Its default remains false.
A v2 sell requires the user volume PDA too. New quote-mint buyback ATAs may need
creation; the Rust wallet planner prepares them from cached state. Old pool
growth rent is included in its budget.

`cargo test -p dex-solana --lib` checks ABI compatibility, selectors, ordering
and privileges; `cargo build-sbf --manifest-path programs/dex-solana/Cargo.toml`
builds the program. Neither proves a new mainnet PumpSwap CPI succeeded. New
Pump multi-hop grouping and bonding-curve v3 are not enabled here.

Local results: all 94 native tests pass and the SBF build succeeds. The rebuilt
router passes the 24-scenario legacy PumpSwap LiteSVM verifier in
`rust-bot/tools/verify-pump-router.py`, including final-return rollback checks.
That verifier uses the older captured PumpSwap ELF and therefore does not
establish new v2 program execution parity.
